# offtrailrun.com

Hi 👋

This is the code for [offtrailrun.com](https://offtrailrun.com), a small bilingual site introducing runners in Eindhoven to off-trail navigation events.

The idea is simple:

- Get a map.
- Find the controls.
- Choose your own route.

## About the site

The site has two parts:

- `/` — the landing page for upcoming runs.
- `/start` — a beginner guide covering map symbols, compass use, and contour lines.

Both pages are available in English and Dutch:

- `/`
- `/nl/`
- `/start/`
- `/nl/start/`

## Tech

Built with Astro, Tailwind CSS, Netlify, and shared EN/NL translation files.
